# 🔥 Primeval Earth Hub

Script Hub cho game **Primeval Earth** trên Roblox - hỗ trợ macOS, Windows, Linux.

## 📋 Tính năng

### ⚔️ Combat
- Auto Attack (tự động tấn công)
- Auto Eat (tự động ăn)
- Auto Aim (tự động ngắm)
- Extended Hitbox (tăng hitbox đánh xa)
- Fly Attack (bay trên đầu để đánh)
- Auto Teleport săn người

### 🏃 Movement
- Speed Modifier (tăng tốc chạy)
- Jump Power (tăng sức nhảy)
- Fly (bay)
- Noclip (xuyên vật thể)
- Water Walk (đi trên nước)

### 👁️ Visuals
- ESP Player (người chơi)
- ESP Dinosaur (khủng long)
- ESP Food (thức ăn)
- ESP Fossil (hóa thạch)
- ESP Zone (khu vực)

### 🌾 Farming
- Fossil Auto Farm
- Auto Collect
- Auto Craft

### 🗺️ Zones
- Auto Zone Control
- Teleport đến zone
- Chiếm đóng tự động
